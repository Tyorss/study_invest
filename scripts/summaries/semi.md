# 반도체 산업분석 정리

## 1. 성장 동력

**시대별 사이클**: PC(`90~`00) → 스마트폰(`00~`20) → AI(`20~)
- `25 글로벌 반도체 시장 $7K억 → `30 $1조 (CAGR 8%)
- 과거 PC·스마트폰에 종속된 경기민감 산업 → 최근 실리콘 가치 밀도(SVD) 급상승으로 **기가 사이클** 진입

**역사적 흐름**: `70 메모리/마이크로프로세서 등장 → `80 일본 DRAM 점령 → `90 미국 회복(PC 보급) → `87 TSMC 설립, 파운드리 모델 탄생 → `00 모바일/팹리스 부상 → `10 10nm 이하 미세화, 중국 진입 → `20~ AI·HBM 중심

---

## 2. 밸류체인 구조

**구분**: 개별반도체(Discrete) vs 집적회로(IC)
- IC = 아날로그IC + **로직IC**(CPU/GPU/AP/NPU) + **메모리**(DRAM/NAND)

**단계**: 설계(Fabless/IDM) → 제조(Foundry/IDM) → 패키징·테스트(OSAT) → 장비·소재

| 단계 | 주요 기업 |
|---|---|
| 팹리스 | NVIDIA, Qualcomm, Broadcom, AMD, Apple |
| IDM | Intel, 삼성전자, SK하이닉스, Micron |
| 파운드리 | TSMC, 삼성전자, UMC, SMIC |
| OSAT | ASE, Amkor, JCET |
| 장비 | ASML, AMAT, Lam, TEL, KLA |

---

## 3. 부문별 점유율 (`25 기준)

- **팹리스**: 미국 68%, 대만 21%(미디어텍), 중국 9%, 한국 1%
- **파운드리**: 대만 66%(TSMC 70%), 한국 17%, 중국 8%, 미국 6% — 5nm 이하는 사실상 TSMC·삼성 양강
- **메모리**: 삼성+SKH+마이크론이 DRAM 95%+. `24~ AI發 슈퍼사이클 시작, `25 SEC·SKH 역대 최고 실적
- **OSAT**: ASE 45% + Amkor 15% → 두 회사가 외주 물량 60%+
- **장비**: ASML이 EUV 100% 독점, DUV도 1위

---

## 4. AI 슈퍼사이클 핵심

**수요 구조 변화**
- CPU 범용 → GPU/ASIC 병렬 연산으로 주도권 이동
- 훈련 → **추론** 중심으로 전환 (`26 인프라 지출의 55%+)
- HBM CAGR 22%, AI 가속기 `30까지 $2K억+ (CAGR 20%+)

**밸류체인 재편**: AI 칩 설계사 + 첨단 파운드리 + 고급 패키징 + HBM/고속 인터커넥트 통합

**생태계 이원화**: NVIDIA CUDA 생태계 vs 빅테크 ASIC 연합(TPU, Trainium 등)

---

## 5. AI 반도체 경쟁 구도

- **엔비디아 80~90% 독점** (H100 → Blackwell → Rubin)
- AMD MI350/MI400으로 추격, Intel Gaudi
- 하이퍼스케일러 자체칩: 구글 TPU, AWS Trainium, MS 에서나 프로젝트, 메타 자체 ASIC 재추진
- Groq 사례: 엔비디아 비독점 라이선스 + 창업자 합류 (M&A 대신 라이선스+인력 흡수 모델)

---

## 6. 수요측(하이퍼스케일러 + 네오클라우드)

- MS/구글/AWS/메타/오라클 **`26 CAPEX 합계 $6K억** (YoY +36%)
- MS는 `24까지 엔비디아 GPU 48만개 확보
- **네오클라우드** 부상: CoreWeave, Lambda, Nebius — 대형 대비 최대 85% 저렴, 글로벌 100개+
- 리스크: AI 수익화 실패 시 CAPEX 위축 → 닷컴버블 유사 우려
